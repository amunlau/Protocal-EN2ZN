# 异常与边缘情况

按实际触发项读取。这里的处理是对 [原文清单流程](long-document-workflow.md)、[水印专项](pdf-furniture.md) 与 [审校规则](quality-and-docx.md) 的补充，不是要求每份 PDF 安装所有工具。

## 解析与 OCR：先保证看到正确原文

| 触发情况 | 处理与可继续条件 |
|---|---|
| 同页同时有可选正文和扫描表格 | 按区域检查覆盖。有一个可选页码不代表整页可读；整页 skip-text 可能漏掉图片内文字。只对缺文字区域补 OCR，按坐标与原文字层对齐，避免双份正文。 |
| 可选文字存在但乱码/乱序 | 对照渲染页检查字形映射和阅读顺序。换提取器或对受影响区域 OCR；能选择文字不等于提取正确，不用拼写纠错猜字段。 |
| 不同原生提取器给出不同技术符号 | 本地真实样本已观察到 pypdf 与 PyMuPDF 对 `×`、`°`、`>` 等符号解码可能不同。逐个对照可见字形、字体/ToUnicode 映射及另一路提取，必要时对局部补 OCR；记录提取器、原值、核实值和定位。禁止字符串全局替换，也不能把某一库的结果无条件当作权威。 |
| 同位置出现双份文字 | 检查是否重复绘制、阴影/粗体模拟或隐藏 OCR 层。只对同字、近同位置且角色一致的重复实例去重并留映射，不对跨位置重复语句全局去重。pdfplumber 的 dedupe_chars 是候选工具，不是水印清除器。 |
| 单页左右栏、侧注、跨栏标题 | 先分区域，再确定阅读路径。源对象绘制顺序和简单按 y/x 排序都可能错；完整句及列末/列首对照原页，表格不能被当正文穿插。 |
| 横向、倒置、混合尺寸、两页合扫 | 核验旋转、CropBox/MediaBox 与坐标原点；预处理后保存到原页/原坐标的变换。两页合扫按阅读序分区，但仍保留原 PDF 页序，不凭新图像页数绕过样本关口。 |
| OCR 低置信、不同引擎数字不一致 | 对照原图逐字符核查；可换分辨率/区域/引擎。两个引擎相同也不能证明正确。0/O、1/I/l、5/S、µ/u、±、−、≤/≥、上/下标、进制尤其要查。 |
| OCR/提取超时、空输出或失败 | 单独登记失败页与原因；可推进无依赖块，覆盖分母不减少。空文本必须核查是空白、纯图、扫描还是解析失败。局部原图保留可供待审稿阅读，不能计为已译正文。 |
| 水印覆盖正文、彩底或细线 | 按水印专项只排除已核实对象。预处理用副本，核对负号、细线、下标和背景变化；不掩膜整块覆盖区，不生成或推测被遮住的字符。 |
| PDF 批注、修订条、附加图层、弹出注释 | 区分正式源版本、编辑批注和显示层。实质内容是否纳入按任务范围判断并记录；不把编辑批注静默合并进规范条款，也不能因页面抽文没出现就忽略源文注释。 |
| 根结构树缺失但局部图中有 MCID/P/Span | 追踪标记所在对象与作用域，不推断全文 tagged 或全文无可用标签；结合原生几何和页图建立读序。 |
| ActualText、Alt 描述与可见文字不同 | 分别记录来源；Alt 不是逐字 OCR。乱码先核对 ToUnicode/字形及原图，不将替代描述当作正文。 |
| 浅色背景、反白字、彩色表头 | 保留底色和文字色；不套统一白矩形覆盖/黑字策略。OCR预处理只用于副本，输出回到原背景与结构。 |
| 原生文字与图内位图文字并存 | 清点每个图内区域，先区分标签、公式、代码和数据；图题有译文不意味着图内已覆盖。 |
| 隐藏 OCR 层或被后绘对象遮住的文字 | 核对与可见内容关系再去重；透明度或不可见本身不构成删除理由。输出检查复制/搜索与可见译文一致。 |

`pdf_probe` 在清单记录 `structure_tree_present`，逐页记录 `rotation/media_box/crop_box/struct_parents`，并统计 U+FFFD、NUL 和 `(cid:` 标记。空文本或这些字符异常使页面标为 `needs_visual_or_ocr`，提取异常另标 `error`。返回的 `failed_pages` 与 `needs_visual_or_ocr_pages` 分别列出失败和待核页，不能把 `extraction_complete` 当作完整可靠正文的证明。这是后续核验提示，不是自动 OCR 或识别结果；没有异常计数也不能证明乘号、角度、比较符号及阅读顺序正确。根结构树布尔值不判断标签质量，也不覆盖所有局部标记。

OCRmyPDF 的 redo/force/skip 在不同版本中参数有变化，先查安装版本及帮助。force 会栅格化内容，redo/force 可使原结构树失效；原生文字和图形质量可能改变。保留原 PDF，OCR 副本不是新的语义权威。sidecar 文本或一次 OCR 成功不代表全篇覆盖；逐页清点跳过/失败区域。依据：[OCRmyPDF](https://ocrmypdf.readthedocs.io/en/stable/advanced.html)、[pdfplumber](https://github.com/jsvine/pdfplumber/blob/stable/README.md)。

## 源文校正与字符保护

保留三层：原始字节/提取快照 → 经页图核实的源文本及校正记录 → 译文。校正记录包含块/页/坐标、原值、新值、原因和核对依据。校正提取器错误不等于修订协议；原页本身有错时保留原意、登记疑点，不按“应该如此”修正。

- 行尾连字符只在确定为排版断词时连接，如跨行的 `implemen- / tation`；保留 `read-modify-write`、负号、范围、料号。不得全局删 `-\n`。页脚先分离再续句。
- 连字 `ﬁ/ﬂ` 可在普通叙述中依据原字形展开；全文 NFKC 会折叠兼容字符/上下标，不能当无损清洗。保留 `µ/μ`、`Ω`、角度、乘号、向量符号、全半角及码点差异的记录。
- 上下标、粗体、斜体可能携带公式、变量、向量或关键字含义；纯文本提取丢失样式时用结构化数学或原图补证。不得把 `x²` 当成 `x2`，也不得把位序 `[7:0]` 反转为 `[0:7]`。
- 代码/ABNF/伪代码、消息模板、正则、URL、路径、格式占位符、转义串保持语法与重复次数；只翻译独立注释及周围说明。字符串字面值若属于线上协议字段，不能按普通英语翻译。
- 源文已有中文或中英对照时先核对是否同一版本，避免再翻一遍形成双份；现有译文只能作为参考，源英文与用户指定的权威版本仍决定内容。

## 表格、图、公式与引用

| 触发情况 | 必须保持的关系 |
|---|---|
| 无边框/多级表头/合并格 | 对照几何和语义还原行列；单元格 ID 与行列/跨度分离存储。空白、0、—、N/A 含义不同，不互填。 |
| 跨页续表 | 核对表号、列定义、单位、行序和续表标记，再连接；跨页重复表头是结构信息，不能当页眉删除。表旁正文不吞入表内。 |
| 每行都有相同数字或相同译词 | 数量守恒不足以定位互换；逐格核对主体/字段/数值/单位/限定条件。新增脚注或单位变更回查所影响的全部数据格。 |
| 位域/寄存器图 | 位编号、位宽、端序、保留位、读写属性、复位值与字段名绑定。相同数字但归属改变是关键错误。 |
| 时序/状态图 | 保留信号名、极性、时间顺序、箭头方向、状态转移条件；图内可译描述单列 ID，标识符不译。图无法安全改标时保留原图并给定位对照，不以只有图注已译宣称全部完成。 |
| 公式/矩阵/多行推导 | 保留运算关系、分母、括号作用域、行列顺序、上下标和公式号；不可可靠转为可编辑公式时保留清晰原图，另译解释。 |
| 脚注编号重复或跨页 | 使用“源页/表/章节 + 原编号”的内部唯一 ID，保留展示编号；绑定锚点和内容，防止跳到另一章同号脚注。 |
| 目录、交叉引用和书目 | 条款/图/表号、标准编号/年份、DOI/URL 保留。明确“原文页码”与译文页码。参考题名可依约加中文，原始检索信息仍保留；本章外引用也建目标状态。 |
| 同表局部加粗/变色、最佳值与显著性符号 | 绑定到具体值及脚注，不随中文重排移到相邻单元格；颜色/字体若表达含义按内容错误验收。 |
| 图内公式、变量下标与描述文字相邻 | 分开保护/翻译，不能把整张图OCR为一句话；标签替换不得覆盖线条、箭头或改变比例。 |
| 审稿行号与算法行号同页 | 前者与正文分离，后者保留算法结构和引用关系；不全局删除页面边缘数字。 |
| 两文件文字完全相同但哈希不同 | 比较页图、图像/矢量、版本和元数据，只标同内容候选；不得自动替换原文件身份或沿用另一源的排版缓存/样本批准。 |
| 原字体子集无中文字形、数学符号替代 | 选择可用目标字体并检查实际字形；保留变量粗斜体及上下标语义。不能用方框、空白或近似字冒充成功。 |

## 语义疑难与项目异常

`may not`、范围不明的否定、`and/or` 嵌套、未知缩写、相互矛盾的表与正文：先查定义、完整条款和引用条款；不能靠一个通用词表消歧。仍不确定则登记具体读法与后果，保持待核，必要时集中向用户询问；不阻塞无依赖部分。

源协议正式勘误与版本升级：核验来源、适用版本和用户任务。默认忠实于指定版本；采纳勘误时登记旧/新条款映射，更新源修订与受影响译文。不能混合两个版本的数字或术语而不说明。

文件/磁盘写入失败、源哈希变化、缓存损坏：停止依赖该输入的写入，保留完整已提交块；恢复按 [项目状态](project-state.md) 执行。新模型输出截断、无 ID 或 ID 重复时拒绝该载荷，不能只凭“成功返回”更新进度。每次失败后依据具体原因缩小工作块/更换解析方式，避免反复对整份 2000 页重跑。

论文/报告中的相同数字不同口径、统计显著性、缩略语多义和引用归属按 [文体专项](document-types.md) 逐项判断。DNT 保护不能豁免同块未译叙述；同一英文重复出现在不同概念或首次/后续实例时使用实例绑定。自动重译或“原文不变就重试”的后端策略不得改写已确认保留的词。

输出适配器无法表示合并格、跨栏、彩底或图文重叠时，应明确拒绝该结构并保持输出待核；可转交有相应能力的工具，不能只忽略不支持字段。已有一种格式生成成功时保留成果，从另一格式的未完成阶段继续，不重译全部正文。排版改变引起内容裁切、脚注移位或跨栏顺序改变时重排和核验，禁止用缩译消除溢出。

## 维护时的行为验收

以下是自拟用例的预期判断，不是已经完成的真实翻译基准：

1. `not all lanes` 译为“所有通道都不……”：应判否定范围错误；数字检查无法发现。
2. `A and B shall be set to 1 and 0, respectively.` 将 A/B 值互换：即使数字总数相同也须判错；逐格载荷可检出格内数值差异，正文仍须语义审查。
3. 仅有页码文字、正文是扫描图：不得判“已有文字，无须 OCR”；发现正文未覆盖。
4. 页顶表头与斜向水印都重复：只排除核实的水印，表头和单位保留；看原页确认。
5. 英文连字符断词与 `write-one-to-clear` 同时出现：修复前者，保留后者及写 1 清零语义。
6. 为避免表格跨页，润色删除 `unless` 子句：拒绝，调整排版后保留完整条件。
7. 有批准样本的项目重启：同源、同约定、同样本应继续；新增检查发现符号问题转待审，保留译文；未曾获批的新会话“继续”不能补造批准。

这些用例中的语义/OCR/版面判断需要实际执行者验证。真实协议验收应按正文、规范条款、表格、图、扫描、水印、跨页和版本冲突分层，记录 critical/major、遗漏、误删、术语错误与返工量；不能用合成测试通过率当翻译准确率。
