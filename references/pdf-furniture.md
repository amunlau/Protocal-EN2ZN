# 水印、页眉和页脚：翻译前强制预处理

命令示例中的脚本路径相对技能根目录，实际执行须展开为绝对路径；PROJECT 是独立的数据目录。环境和跨工具迁移见 [适配指南](platform-compatibility.md)。

## 处理目标

已确认水印不翻译，不作为正文、脚注、图注、术语或翻译记忆输入。重复页眉、页脚、页码与正文分离，默认不逐页翻译；文档名、版本和印刷页码留在元数据与定位表。中文 Word 的页眉页脚由项目样式统一生成。

仅改变翻译输入的构成，保留原始 PDF、原始提取、页图及排除记录。源图中可见的水印也不作为需要翻译的图内标签；本流程不自动擦除源图水印。按“对象 + 页 + 位置 + 来源哈希”定位，不能全局删词。

## 推荐方法：多种证据交叉核验

1. **结构标记。** 检查 Artifact/Pagination 及 Header、Footer、Watermark 属性，或布局工具的 page_header/page_footer/furniture 标签。标签可能缺失、误标或只被部分提取，必须核对内容和页图。Artifact 不一定是水印，没有标签也不等于没有水印。W3C 与 PDF Association 说明了页面装饰与逻辑正文的分离，见来源 S21–S22。
2. **跨页模板。** 综合归一化位置、字体字号、文本相似性与重复出现，按章、奇偶页、章首页、封面目录、附录、旋转页及纸张尺寸分别判断。章名变化的页眉不一定全文同字。2000 页按版式/章节分组，不能用全书多数票覆盖少量特殊页。
3. **水印外观。** 斜向、大字、浅色/透明、跨正文叠放、重复图像或绘制对象可提供证据；竖排表头、坐标轴、图中大字、灰色注释也可能有这些特征。工具取不到透明度或完整变换矩阵时标未知，不能虚构证据。
4. **视觉与语义复核。** 叠框对照原页、候选与正文。每种模板看首/中/尾、奇偶页、模板切换和异常页；单例逐页核验。由执行者审查，不额外要求用户逐项批准；样本确认仍由用户完成。

上下约 10%–12% 只能用于候选检索，不能固定裁剪。只有完整页码形式才可做数字归一化，不能将正文条款号、版本、日期、数值全部泛化后去重。字符串重复、位于边缘、斜体/旋转或 Artifact 标记，任何单项都不能直接触发删除。

## 必须保护的反例

| 情况 | 处理 |
|---|---|
| 正文有 DRAFT、CONFIDENTIAL 或与水印相同的词 | 按正文语义处理，仅排除水印实例 |
| 重复表头、Reserved、单位或标准警告 | 保留结构作用，不能因为重复而删除 |
| 页底脚注、表下注、公式注、版权/许可实质条款 | 与纯重复页脚分开，保留并绑定相关内容 |
| 页顶章节标题、章首页大标题、页底正文 | 保留，不能套后续页模板直接裁掉 |
| 页码与章节号形式相同 | 结合位置和上下文，仅排除页码对象 |
| 一个提取块同时包含水印和正文 | 下钻字符/对象分离，不删除整块，不涂白重叠矩形 |
| 奇偶页左右互换、章名或版本变化 | 分模板与作用范围处理 |
| 页脚夹在跨页句子中间 | 先排除对应页脚对象，再连接句段并保留原页映射 |

## 图片、矢量与扫描件

水印可能烧入像素、转成路径或以图片浮层存在。检查原页渲染与带词框的 OCR/布局输出；比较代表页的几何和重复纹理，不把真实图表当作重复背景。

优先从 OCR 结果中排除已确认的水印词框，保留原页。水印覆盖正文像素时，不用大块掩膜、自动修复或重绘猜测字符；可更换渲染分辨率/识别方式并对照清晰来源，仍不可读则待核。去斜、对比度调整仅作用于副本，检查是否损坏位图、细线、公式和数字。清洗后再次检查 OCR 是否把浅色水印送入正文。

文字提取未发现水印不代表图像无水印。无 OCR/图像能力时，受影响页保持待核，不能标为清洗完成。

特别区分“工具不加输出水印”和“识别源 PDF 水印”：例如 BabelDOC 的 `watermark-output-mode=no_watermark` 表示不添加其输出水印，不证明源水印已移除或未被送译。表格文字、图内文字、扫描页等选项也须逐项核对默认行为，不能只凭成品看似保版式就判完整。依据见 [BabelDOC 原始选项](https://github.com/funstory-ai/BabelDOC/blob/main/README.md)。

重复文字层去重、OCR 和旋转矫正都可能改变片段 ID/坐标。先保留原始对象与转换映射，再按新处理版本重建候选和审查记录，不能把旧排除 ID 直接套到新提取结果。带文字页码的扫描页尤其不能因“有文字”跳过正文 OCR；详见 [异常处理](edge-cases.md)。

## 工具流程

`scripts/pdf_furniture.py extract` 需要 pdfplumber，analyze/apply 仅需标准库。它缓存字符流片段的位置、字体、角度、颜色和 tag；**本版本不解析透明度、完整 Artifact 子类型或图片内容，不保证复杂阅读顺序**。S23–S25 记录相关能力与局限。

```text
python scripts/pdf_furniture.py extract SOURCE.pdf --cache PROJECT/layout-cache --start 1 --end 100
python scripts/pdf_furniture.py analyze --cache PROJECT/layout-cache --report PROJECT/furniture-report.json --start 1 --end 100
```

extract 可续提；源或提取器版本变化用新缓存。analyze 默认要求全部页面齐全，分批时明确范围；部分页的报告不等于全文通过。跨批检查邻页并统一模板，同时保留局部例外。范围扩大后须重新绑定报告和审查决定。

当前适配器版本 2 对普通横排字符额外区分字号、结构 MCID 与明显间距，避免分开定位的单词被拼成一个词、上下标混成同字号片段。旋转文字的边界框字号会随字符宽度变化，不机械按该值切碎水印。新旧片段 ID 不可直接互套；旧缓存继续作为证据保留，重新提取后按源修订机制核对映射。分析报告必须放在布局缓存之外，不能覆盖源 PDF；不同页的片段 ID 也必须全局唯一。

报告只生成候选，包含 ID、原文/坐标、证据、分组和代表页。轻量检测可能漏检动态章名、图片水印等，须以全文页图筛查及必要的布局/OCR 能力补足。未入候选的对象若需排除，使用适当适配器产生新的版本化布局数据并补 role 字段，再重新分析，不直接改原始缓存或全文替换。

对照原页后写审查文件。以下仅示意字段，不能当成已完成的审查证据：

```json
{
  "report_sha256": "当前报告 sha256",
  "reviewer": "实际执行者",
  "reviewed_at": "实际含时区时间",
  "page_screening": "实际全页筛查范围、模板抽查策略和异常页处置",
  "groups": [
    {"group_id":"实际分组 ID","action":"exclude","classification":"header","reason":"实际位置、跨页和语义依据","verified_pages":[1,50,100]}
  ],
  "items": [
    {"id":"实际片段 ID","action":"keep","reason":"表下注应保留","visual_check":"实际原页定位和核验结果"}
  ],
  "image_vector_reviews": {
    "实际页码": {"disposition":"no_watermark","evidence":"实际图像/矢量核验结果；已另行处理则用 handled_separately 并指向成果"}
  }
}
```

分组决定核验至少 3 页，不足 3 页时核验全部；逐项决定覆盖分组，可保留特殊页例外。所有候选均需 keep/exclude；exclude 限 watermark/header/footer/page_number。未处置完，或缺图片/矢量/无文本页额外核验记录时，apply 停止。脚本检查记录完整性，不能证明实际看过页图或分类正确。

```text
python scripts/pdf_furniture.py apply --cache PROJECT/layout-cache --report PROJECT/furniture-report.json --decisions PROJECT/furniture-decisions.json --output PROJECT/body-cache-v1
```

输出保留片段及原文位置，另存 exclusions.json、decisions.json、manifest/receipt。保留对象与排除对象无交叉，合计覆盖全部输入片段。没有 receipt 的输出不完整，可按相同输入重跑；规则变化用新目录保留旧版本。

同版本重跑会校验并复用未变化的正文候选页，只重写损坏/缺失页。修复开始前撤下旧 receipt，全部成功后再写新 receipt，避免中断后旧完成标记掩盖部分损坏。manifest 仅表示作业身份，不是完成证明。

输出仅是经审查的**文字层过滤结果**，仍须核验阅读顺序、OCR、图像与表格结构。inventory 引用源页、保留片段 ID、processing_sha256；coverage.json 记录排除对象。已译项目的清洗规则变化须建立修订映射，回查受影响译文、术语、样本和文档。

## 验收

样本包含实际水印/页眉页脚和存在的易误删脚注/表头。核对清洗前后正文，确认条件、否定、数字、公式和图表未丢失。全文按章/版式检查模板边界和异常页。

检查排除 ID 是否进入 inventory、术语和译文；搜索水印文本及可能中文译法作为泄漏线索，再按位置/语境判断，不能误删正文同名词。水印漏入或正文误删都阻断交付。报告实际处理与待核范围，不承诺任何 PDF 都能自动百分之百识别。
